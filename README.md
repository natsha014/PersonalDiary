# Приложение интернет-магазина

## Описание

Проект на Django для управления каталогом товаров и формой обратной связи.

## Функционал
 
 - Просмотр списка товаров (Home).
 - Форма обратной связи на странице контактов (Contacts).
 - Логирование и обработка данных пользователей.

## Технологии

 - Python версии 3.13
 - Django 6.0.1
 - Bootstrap 5.3.8 (для стилизации форм)


## Установка и запуск

### Клонируйте репозиторий:

```
git clone https://github.com/natsha014/Project4Django
```

### Создайте и активируйте виртуальное окружение:

```
python -m venv venv
source venv/bin/activate  # Для macOS/Linux
venv\Scripts\activate     # Для Windows
```

### Установите зависимости:

```
pip install -r requirements.txt
```

### Запустите сервер:
```
python manage.py runserver
```

## Использование формы контактов
При переходе на страницу `/contacts/` доступна форма. 

При заполнении полей `name` и `message` и нажатии кнопки `"Отправить"`, 

данные передаются **методом POST**, и сервер возвращает подтверждение.


### Особенности реализации

Для обработки формы используется единая функция-представление `(View) contacts`, 
обрабатывающая как **GET**, так и **POST** запросы.

Реализована защита от **CSRF**-атак.

Используются **URL** со слэшем на конце для предотвращения потерь **POST**-данных.
